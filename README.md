# AvrStb6-wheat microbiome interactions
This GitHub repository contains the code and data analyses associated with the manuscript:
Florez L. et al. (2026). An effector protein that protects a fungal pathogen from the plant microbiota during host colonisation. bioRxiv. https://www.biorxiv.org/content/10.64898/2026.06.10.731356v2
## Objective
This repository provides the datasets and R scripts used to generate the analyses and figures presented in the manuscript, allowing the analyses to be reproduced.

## Repository structure
The repository contains four folders corresponding to the analyses used to generate Figures 2–5 of the manuscript.
Figures 1 and 6 did not require R or any other integrated development environment and are therefore not included.
Where appropriate, analyses were performed independently for each panel (for example, Figure 2A).
Each analysis folder contains:
* an R Markdown (.Rmd) file;
* the raw input data (.csv);
* output files generated by the analysis (for example .png, .xlsx, and .pdf).
## Reproducing the analyses
For each figure folder:
1. Open the .Rmd file in RStudio.
2. Ensure that all data files in the folder are present.
3. Install any required R packages if necessary.
4. Run the entire document ("Run All") to reproduce the analysis and generate the output files.
## Requirements
The analyses require the installation of the R packages listed within each R Markdown file.
